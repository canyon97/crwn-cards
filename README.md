# CRWN Cards

A modern and responsive React application for creating a full-fledged (mock) shopping experience for Pokémon cards, featuring a polished and user-friendly design.

## Features

- **Card Catalog**: Browse a wide selection of Pokémon cards with detailed information.
- **Search Functionality: TODO**: Quickly find cards by name or type using the search bar.
- **Shopping Cart: TODO**: Add, remove, and manage cards in your shopping cart.
- **Checkout Process: TODO**: Simulate a seamless checkout experience.
- **Responsive Design**: Optimized for all screen sizes, from mobile to desktop.

## Tech Stack

- **Frontend**: React with Vite for fast development and hot module replacement.
- **Styling**: TailwindCSS for a modern and responsive UI.
- **Data**: Mock Pokémon card data fetched from a local or external API.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/canyon97/crwn-cards.git
   ```
2. Navigate to the project directory:
   ```bash
   cd crwn-cards
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
